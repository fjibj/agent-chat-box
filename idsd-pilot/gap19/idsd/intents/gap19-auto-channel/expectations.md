# 期望：GAP-19 自动创建群聊频道

## 成功场景

| 场景 | 期望行为 |
|------|----------|
| 通过 UI 创建群 | 点击 "Create" 后，Chat 页面的频道列表中出现一个名称派生自该群的新频道。 |
| 通过 API 创建群 | `POST /api/groups` 返回群信息的同时包含 `channel_id` 字段；`channels` 表中存在 `type='group'` 的对应记录。 |
| 群主团队成员关系 | 群主团队会自动以 `member_kind='human'` 的身份，使用稳定的群主用户标识加入 `channel_members`。 |
| 频道名称唯一性 | 多个群可以共存；它们的频道拥有不同 ID，不会冲突。 |

## 失败场景

| 场景 | 期望行为 |
|------|----------|
| 群创建失败 | 数据库中不会残留部分频道记录。 |
| 群名重复 | 频道创建仍然成功，因为频道身份绑定的是群 ID，而非群名。 |

## 边界场景

| 场景 | 期望行为 |
|------|----------|
| 已存在的群 | 本次修复前创建的群仍保持无专用频道；只有新创建的群才会获得频道。 |
| 解散群 | 删除群时，应同时清理其自动创建的频道及成员关系（级联或显式清理）。 |
| 联邦成员入群 | 当新团队加入一个已有自动创建频道的群时，**不**自动将其加入该频道（超出本次修复范围）。 |
