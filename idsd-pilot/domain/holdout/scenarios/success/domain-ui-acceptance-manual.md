# MANUAL：域层 UI 人工验收清单

启动 `npm run dev`（或构建后打开 web），以人工方式逐项验收 DomainsPage。每项标注 ✅ / ❌。

## 导航与入口
- [ ] 导航栏出现 "Domains" 项，点击进入 `/domains` 路由，无 404。
- [ ] 页面深色主题与现有页面（Groups/Tasks）一致，无布局破损。

## 群选择器
- [ ] 无任何群时：显示"先创建/加入群"的引导提示。
- [ ] 有群时：下拉可选择当前操作群，切换后域列表随之刷新（以新群身份）。

## 域列表 / 创建 / 加入
- [ ] 当前群参与的域以列表展示（名称、成员数等）。
- [ ] 创建域：输入名称创建成功，新域出现在列表，owner 显示为当前群。
- [ ] 加入域：输入邀请码加入成功，域出现在列表。
- [ ] 空状态：无域时显示创建/加入入口的引导。

## 域详情
- [ ] 展开域详情：成员列表（群名 + 角色 + 能力）正确展示。
- [ ] 生成邀请码：点击后展示新邀请码。
- [ ] 退出：owner 点击退出 → 显示被拒提示（"请解散域"）；member 可退出，退出后域从列表消失。
- [ ] 解散：仅 owner 可见解散入口；解散前有确认弹窗；解散后域从列表消失。

## 能力声明
- [ ] 以当前群身份声明能力（输入/选择能力标签）成功，成员能力列表立即更新。
- [ ] 能力列表正确展示各成员声明的能力。

## 发现
- [ ] 输入能力关键词搜索，返回匹配成员，展示信誉分（数字）与 flagged 标记（如存在）。
- [ ] 无匹配时给出空结果提示。

## 协作任务
- [ ] 发起协作：填写标题 + 选择所需能力，提交成功，任务出现在任务列表。
- [ ] 无匹配群（能力无人声明）→ 显示 400 错误提示，页面不崩溃。
- [ ] 任务列表正确展示（任务标题、状态、发起方/目标群）。
- [ ] 对已完成任务评分（approved / rejected）成功，页面有反馈。

## 信誉看板
- [ ] 展示各成员群信誉分（数字），按信誉排序可见。
- [ ] 连续 5 次 rejected 的群显示 flagged 标记（如能构造）。

## 错误处理与稳定性
- [ ] 非成员群访问域数据（如以未加入的群身份操作）→ 显示 403 错误提示，页面不崩溃。
- [ ] 浏览器控制台无未捕获异常 / 网络 4xx 之外的报错。
