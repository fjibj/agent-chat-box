# 期望：切片 4 —— 多域交互的边界处理

## 成功场景

| 场景 | 期望行为 |
|---|---|
| 信誉隔离 | 群 B 同属域 D1、D2：B 在 D1 的协作评分（rejected）只影响 B 在 D1 的信誉，B 在 D2 的信誉保持 0 |
| 跨域不可见 | 群 B 在域 D1 的协作任务不出现在域 D2 的任务列表中；D2 成员访问 D1 的协作任务列表 → 403 |

## 失败场景

| 场景 | 期望行为 |
|---|---|
| 退出后评分 | 目标群 B 退出域后，原协作任务评分 → 404（任务索引已清理） |

## 边界场景

| 场景 | 期望行为 |
|---|---|
| 解散域清理 | 域内存在协作任务时解散域 → 域 API 全部 404（domain_tasks 已随域清理） |
| 退出域清理 | 群 B 退出域后，其协作任务从域任务列表消失，且不可再评分（404） |
| 删群清理 | 删除域成员群 B → B 从能力列表/域任务列表消失；删除域 owner 群 → 该域被解散（404），其协作任务索引一并清理 |
