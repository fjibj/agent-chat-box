# 期望：切片 2 —— 能力发现与信誉查询

## 成功场景

| 场景 | 期望行为 |
|---|---|
| 群声明能力 | 成员群更新能力声明后，域能力列表中该群的能力变为更新后的值 |
| 能力发现精确匹配 | 群 A 查询能力 X：声明包含 X 的群被返回，声明不包含 X 的群不出现；查询 X+Y 时只有同时具备两者的群被返回 |
| 发现结果含信誉 | 发现返回的每个群都带 reputation 数值（无记录时为 0） |
| 域信誉查询 | 信誉接口返回该域所有成员群及其信誉值（数值，无记录为 0） |

## 失败场景

| 场景 | 期望行为 |
|---|---|
| 非成员声明能力 | 非成员群调用能力声明 → 拒绝（403） |
| 非成员发现查询 | 非成员群调用能力发现 / 信誉查询 → 拒绝（403） |

## 边界场景

| 场景 | 期望行为 |
|---|---|
| 空 required 查询 | required 为空时返回该域全部成员群 |
| 群退出域 | 退出后其能力与信誉从该域的发现/信誉/能力列表中消失 |
| 无任何能力声明 | 未声明能力的群不会被非空 required 的发现命中 |
