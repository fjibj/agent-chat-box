# 期望：切片 5 —— 域层 UI（DomainsPage）

## 成功场景

| 场景 | 期望行为 |
|---|---|
| 域列表 | 选择当前群后展示其参与的域（名称、成员数等） |
| 创建域 | 输入名称创建成功，新域出现在列表且 owner 为当前群 |
| 加入域 | 输入邀请码加入成功，域出现在列表 |
| 能力声明 | 当前群声明能力成功，成员能力列表可见该声明 |
| 发现 | 按能力搜索返回结果，展示信誉分与 flagged 标记 |
| 协作 | 发起协作成功出现在任务列表；评分成功并反映到信誉看板 |
| 信誉看板 | 展示各成员群信誉分，异常群带 flagged 标记 |

## 失败场景

| 场景 | 期望行为 |
|---|---|
| 非成员操作 | 以非成员群身份访问域数据 → 显示 403 错误提示，页面不崩溃 |
| owner 退出 | owner 尝试退出 → 显示被拒提示（需解散域） |

## 边界场景

| 场景 | 期望行为 |
|---|---|
| 空状态 | 当前群未参与任何域 → 显示空列表引导（创建/加入入口可见） |
| 无匹配群 | 发起协作无能力匹配群 → 显示 400 错误提示 |
| 无群上下文 | 群列表为空 → 提示先创建/加入群 |
