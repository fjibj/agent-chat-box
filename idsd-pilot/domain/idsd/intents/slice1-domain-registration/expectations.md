# 期望：切片 1 —— 域的数据模型与注册 API

## 成功场景

| 场景 | 期望行为 |
|---|---|
| 群创建域 | 群 A 创建域后，域创建成功；群 A 自动成为域成员，角色为 owner；域详情中能看到群 A 及其 owner 角色 |
| 其他群凭邀请码加入 | 群 A 为域生成邀请码，群 B 凭邀请码加入后成为 member 成员，域的成员列表包含群 B |
| 群加入多个域 | 群 B 加入域 1 和域 2 后，两个域的成员列表都包含群 B，互不影响 |
| 查看所属域 | 群 B 查询域列表，能看到自己所属的全部域；非成员群看不到该域 |
| 群退出域 | member 角色的群退出后，域成员列表不再包含该群；该群域列表中不再出现该域 |

## 失败场景

| 场景 | 期望行为 |
|---|---|
| 无效邀请码 | 用不存在的邀请码加入域 → 拒绝 |
| 过期邀请码 | 用已过期的邀请码加入域 → 拒绝 |
| 超次数邀请码 | 邀请码达到最大使用次数后再加入 → 拒绝 |
| owner 试图退出 | 域主群调用退出接口 → 拒绝（只能解散域） |
| 重复加入 | 已在域中的群再次凭邀请码加入同一域 → 拒绝 |

## 边界场景

| 场景 | 期望行为 |
|---|---|
| 解散域 | 域主群解散域后，域的成员关系全部清理；任何群查询该域 → 404 |
| 邀请码校验 | 加入成功后邀请码使用次数 +1；多次使用按 max_uses 限制 |
| 群不属于任何域 | 群查询域列表返回空数组（不是错误） |
| 缺 owner_group_id | 创建域时缺少 owner_group_id → 400 |
