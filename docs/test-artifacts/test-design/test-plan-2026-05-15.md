## 1. Objectives

- Validate DB migrations v4→v5→v6→v7→v8 are idempotent and backward-compatible
- Validate all new REST API endpoints return correct status codes and data shapes
- Validate WebSocket group broadcast delivers messages within 5s for 50-team scale
- Validate cross-team claim + authorization flow (manual + auto) works end-to-end
- Validate reputation scoring and threshold decisions are accurate
- Validate UI components render correctly and interact with APIs
